## 슬라이드 3: 통합 로그인 시스템 (1분 30초)

"첫 번째 보완 과제, 통합 로그인입니다.

왼쪽이 기존 상태입니다. Nextcloud, Paperless, ArchiveBox 각각 별도로 로그인해야 했습니다.
사용자가 서비스마다 계정을 기억해야 하고, 관리자는 서비스마다 계정을 생성해줘야 하는 부담이 있었습니다.

오른쪽이 개선된 상태입니다.
포탈에서 한 번 로그인하면 역할에 따라 관리자와 직원 화면이 다르게 보이고,
서비스 대시보드에서 바로 각 서비스로 접속할 수 있습니다.

JWT 세션 토큰 기반으로 구현했고, 향후 OIDC 프로토콜을 적용하면
포탈 로그인 한 번으로 각 서비스까지 자동 로그인되는 완전한 SSO를 구현할 수 있습니다."

## 슬라이드 4: 보안 강화 (1분 30초)

"두 번째 보완 과제, 보안 취약점 분석 및 강화입니다.

4개 계층으로 보안을 설계했습니다.

1계층, Cloudflare Tunnel입니다. 서버의 실제 IP가 외부에 노출되지 않고, DDoS 공격도 방어됩니다.

2계층, Cloudflare Access입니다. 관리자 페이지에 접근하려면 이메일 OTP 인증이 필요합니다.
허가된 이메일만 접근할 수 있는 Zero Trust 방식입니다.

3계층, API 토큰 인증입니다. 서비스 제어 요청마다 SHA-256 해시된 토큰을 검증하고,
역할에 따라 접근 가능한 서비스와 행동을 제한합니다.

4계층, 감사 로그입니다. 누가, 언제, 어떤 조작을 했는지 모든 기록이 JSON Lines로 남습니다."

## 예상 질문 & 답변

**Q: 통합 로그인이 실제로 각 서비스에 자동 로그인되나요?**
> "현재는 포탈 레벨의 통합 로그인이고, 각 서비스는 아직 별도 로그인이 필요합니다. OIDC 프로토콜을 적용하면 완전한 SSO가 구현되며, 향후 과제로 계획하고 있습니다."

**Q: 보안이 실제로 안전한가요?**
> "Cloudflare의 기업용 보안 인프라를 무료 플랜으로 활용하고 있습니다. 오리진 IP 비노출, TLS 1.3, 이메일 OTP 인증이 적용되어 있고, 감사 로그로 모든 행위를 추적합니다."

**Q: 중간발표 이후 실질적으로 뭐가 달라졌나요?**
> "통합 로그인 UI, 4계층 보안 체계 정리, 불필요 서비스 제거 및 인프라 정비, UI 리디자인을 진행했습니다."

**Q: 게임 서버는 왜 있나요?**
> "온디맨드 서비스 제어의 실제 사용 사례입니다. WOL로 원격 부팅하고 유휴 시 자동 종료하는 같은 메커니즘을 업무용 서버에도 적용할 수 있습니다."

**Q: AI 도구를 사용했나요?**
> "개발 과정에서 AI 코딩 도구를 활용했습니다. 아키텍처 설계와 인프라 구축, 서비스 운영은 직접 수행했고, UI 구현과 코드 작성에 AI를 보조 도구로 사용했습니다."
